# Frontend — 72º Encontro de Casais INVA

Aplicação **React** desenvolvida com **Tailwind CSS**, **Lucide Icons** e **Motion**.

---

## 💻 Como Rodar o Frontend Localmente

```bash
# Na pasta frontend:
npm install
npm run dev
```

A aplicação abrirá no endereço `http://localhost:3000`.

### Integrações Ativas

1. **Backend Fastify:** Envia requisições para `POST /api/registrations`.
2. **Google Forms Oficial:** Envio direto para o `formResponse` da planilha da igreja.
3. **PagBank Sacola Oficial:** Redirecionamento com cálculo de lote e parcelamento em até 12x.
4. **Gerenciador Local de Comprovantes:** Salva e permite exportação em planilha CSV e envio no WhatsApp.
